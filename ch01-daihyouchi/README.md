# 第1章 平均・中央値・最頻値

『Pythonで学び直す統計・確率』の第1章のサンプルコードです。
Google Colab に貼り付けて ▶ で動きます（ブラウザだけで動きます）。

## 収録している LESSON

- **LESSON 01** 平均所得536万円なのに、「そんなにもらってない」のはなぜ?
- **LESSON 02** 「普通の人」の値が知りたい: 中央値
- **LESSON 03** 靴屋の仕入れはなぜ平均サイズではダメか: 最頻値
- **LESSON 04** 1万人の数字は「束ねて」見る: 度数分布表とヒストグラム
- **LESSON 05** 本物の日本の所得分布を描く

## 実行のしかた

**まずはファイルの中身を全部貼り付けて、上から順に実行するのがおすすめです。**

1. [`chapter01.py`](./chapter01.py) を開き、右上の **Raw** ボタンを押します。コードだけの画面になったら全選択（Windows は Ctrl+A、Mac は Cmd+A）してコピー
2. [Google Colab](https://colab.research.google.com/) の新しいセルに貼り付け
3. ▶ を押します（見つからないときは Shift+Enter でも実行できます）

ファイル冒頭に日本語フォントの設定（`!pip install matplotlib-fontja`）が入っているので、グラフの日本語も文字化けしません。この行はそのまま実行してください。
